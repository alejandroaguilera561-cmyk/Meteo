🏫 Sobre PRONÓSTICO-ZAP

🎯 Objetivo
Registrar variables meteorológicas y presentarlas de manera sencilla para que cualquier persona pueda comprenderlas.
🔬 Sensores
DHT11 para temperatura y humedad, BMP280 para presión, sensor de lluvia y anemómetro para el viento.
💻 Sistema
Los datos de los sensores serán integrados posteriormente al sistema de visualización.
📱 Acceso
La página está preparada para utilizarse desde computadoras, celulares y tablets.
